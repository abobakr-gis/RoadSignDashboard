# Road Sign Spotter — داشبورد مجاني بالكامل (بالمتصفح)

أداة مطابقة لوحات الطريق، لكن بدون أي برنامج يتثبت، بدون مفتاح API، وبدون أي
تكلفة خالص. كل حاجة بتشتغل جوه متصفح الفرد نفسه.

## 🧠 إزاي بتشتغل مجانًا؟

بدل ما نستخدم Claude Vision عبر الإنترنت (وده اللي بيتكلف فلوس)، الصفحة
بتحمّل نموذج ذكاء اصطناعي مفتوح المصدر اسمه **CLIP** (حجمه ~90 ميجا) مرة
واحدة بس على جهاز كل فرد، ويشتغل من بعدها بالكامل جوه المتصفح - من غير
إنترنت حتى (بعد أول مرة). CLIP بيفهم *معنى* اللوحة (شكلها/لونها/رمزها)
مش بكسلاتها، فبيفرق كتير عن الطريقة القديمة اللي كانت بتفشل.

**أول مرة** يفتح فيها أي فرد الصفحة:
1. المتصفح بينزل نموذج CLIP (~90MB، مرة واحدة، بيتخزن تلقائيًا في cache
   المتصفح).
2. الصفحة بتحسب "بصمة" ذكاء اصطناعي لكل صورة من صور الكتالوج الـ329
   (بياخد حوالي دقيقة، شريط تقدم هيظهرله). النتيجة بتتخزن في `localStorage`
   بتاع المتصفح، فمرات بعد كده هتفتح فورًا.

من ساعتها، أي صورة يرفعها أو يلتقطها، هتتقارن بالمعنى مع الـ329 لوحة في
أقل من ثانية.

## 🚀 خطوة النشر (اختار واحدة بس)

### الخيار أ - GitHub Pages (زي طريقتك المعتادة، وأفضل خيار)

1. اعمل مستودع (repo) جديد على GitHub، وارفعله محتويات مجلد
   `RoadSignDashboard` كلها (نفس الطريقة اللي عملتها قبل كده لداشبوردات
   NWC/Ha'il/Qassim).
2. من إعدادات المستودع فعّل **GitHub Pages** (Settings → Pages → Deploy
   from branch → main).
3. هيديك رابط زي:
   `https://<username>.github.io/<repo-name>/`
4. ابعت الرابط ده لكل فريقك على WhatsApp - يفتحوه في Chrome وخلاص، مفيش
   تثبيت أي حاجة.

### الخيار ب - سيرفر محلي بسيط (لو عايز تجرب على جهازك بسرعة الأول)

لازم تفتح الصفحة عن طريق سيرفر (مش بدبل كليك مباشر على الملف) عشان ميزة
"التقاط الشاشة" تشتغل صح. لو عندك Python مثبت:

```
cd RoadSignDashboard
python -m http.server 8000
```

بعدها افتح المتصفح على: `http://localhost:8000`

> **ملحوظة:** خاصية "ارفع صورة" (📁) بتشتغل حتى لو فتحت الملف مباشرة
> بدبل كليك من غير سيرفر. خاصية "التقط من الشاشة" (🖥️) بس هي اللي محتاجة
> رابط https أو localhost عشان المتصفح يسمح بمشاركة الشاشة.

## 🎯 طريقة الاستخدام

1. افتح الرابط (أو الصفحة) في **Google Chrome** (الأفضل توافقًا).
2. استنى أول مرة بس لحد ما يخلص تجهيز النظام (شريط تقدم فوق).
3. عندك طريقتين للإدخال:
   - **📁 ارفع صورة** - أسهل وأسرع طريقة، اختار صورة اللوحة مباشرة.
   - **🖥️ التقط من الشاشة** - لو بتراجع فيديو أو صور جوه برنامج تاني:
     دوس الزرار، اختار الشاشة/النافذة اللي فيها الفيديو، دوس
     "📸 التقط الإطار الحالي" لما تشوف اللوحة، وارسم مربع حوالينها بالماوس.
4. النتائج هتظهر تلقائيًا مرتبة (⭐ الأقرب في الأول) مع نسبة تطابق.
5. دوس على اللوحة الصح -> بتتسجل في السجل تحت تلقائيًا.
6. لو مش لاقي اللوحة صح، استخدم مربع البحث اليدوي بالاسم/الكود.

كل فرد نتايجه بتتخزن في متصفحه هو بس (`localStorage`)، وممكن أي وقت يدوس
**⬇️ تصدير CSV** عشان يبعتلك ملف نتايجه.

## ⚠️ حدود مهمة تعرفها

- **مفيش حفظ مركزي تلقائي:** كل فرد النتايج بتاعته في متصفحه بس. لازم
  كل واحد يصدّر CSV ويبعتهولك انت تجمعهم (زي فكرة `merge_results.py`
  القديمة، تقدر تستخدم نفس الفكرة مع ملفات الـ CSV دي).
- **لو مسح الفرد بيانات المتصفح (Clear browsing data):** السجل والكاش
  هيتمسحوا. خليهم يصدّروا CSV بانتظام.
- **الدقة:** CLIP أفضل بكتير من الطريقة القديمة (phash) لكن أقل شوية من
  Claude Vision المدفوعة. في الحالات النادرة اللي مش متأكد فيها، فيه بحث
  يدوي دايمًا كخيار احتياطي.
- **المتصفح:** Chrome أو Edge (الأحدث) هما الأنسب. Safari ممكن يشتغل
  بس مش مضمون 100%.

## 🔧 لو حصلت مشكلة

- **"جاري تجهيز النظام" فاضل واقف:** تأكد إن فيه إنترنت شغال (محتاج مرة
  واحدة بس لتنزيل النموذج). جرب Refresh.
- **زرار "التقط من الشاشة" مش شغال / بيديك رسالة خطأ:** لازم تفتح الصفحة
  عن طريق رابط https (GitHub Pages) أو localhost - مش بدبل كليك مباشر
  على الملف.
- **النتائج مش دقيقة:** استخدم مربع البحث اليدوي، وقولّي عشان أظبط
  الموديل أو أرفع دقته.
